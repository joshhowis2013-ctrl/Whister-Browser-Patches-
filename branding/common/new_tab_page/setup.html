01 / Default browser

Make Whister your default?

Set Whister as the browser Windows uses for web links. This opens the browser’s real Default browser setting in a new tab.

Default browserWindows may ask you to confirm the change. Open Default browser settings ↗

02 / Search

Choose your search engine

This becomes the search provider used from Whister’s address bar.

03 / Bring your things

Import bookmarks and settings

Bring over available bookmarks, history, passwords, search engines, and autofill data from another browser.

Import browser dataThe import page shows the browsers and data types detected on this device. Open Import settings ↗

Nothing is imported until you choose data and confirm it on the Import page.
